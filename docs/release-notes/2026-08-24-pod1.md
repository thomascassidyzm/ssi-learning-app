# Release — 24 August 2026 (afternoon)

## What changes for learners

**New listening conversations, on most courses.**

If you learn in one of the languages below, the Dialogues in your course have been
replaced with a new, much longer set — 231 lines instead of the short set you had
before. It is the same idea, with a lot more of it: two people talking, at a pace you
can follow, so you get used to hearing the language rather than only producing it.

The other change you will hear straight away is the voices. Every conversation is now
cast properly — a male and a female speaker, held consistently, so the two people in a
dialogue never sound like the same person. On the old set they sometimes did, and it
made a conversation surprisingly hard to follow.

**Your place is kept.** If you were partway through the old dialogues, your progress has
been carried across to the matching point in the new ones. You do not start again.

Live now in: Arabic · Egyptian Arabic · German · Austrian German · Basque · French ·
Canadian French · Irish · Hindi · Croatian · Italian · Japanese · Korean · Dutch ·
Portuguese · Brazilian Portuguese · Romanian · Spanish · Mexican Spanish · Swedish ·
Chinese.

**Not every course yet.** These are the courses where every single line was finished and
checked on both sides — the language you are learning and the language you are learning
it from. Where anything was still outstanding, we have left the old dialogues in place
rather than ship you a half-finished set. Icelandic and a further batch are close and
come in the next release.

## Also in this release

**Downloads can no longer hand you an unreleased conversation.** When a new set of
dialogues is being prepared, it sits in the course database before it is ready for
anyone to hear. The offline-download route did not check that, so in principle a
download could have pulled a set that was still being worked on. It now checks, and
refuses. Nobody is known to have hit this — the fix closes the door before the new
dialogues started moving through it, which is exactly when it mattered.

**Offline downloads were carrying the old dialogues too — fixed.** When the new
conversations went live this morning, the sets they replaced were archived, but not
actually marked as retired. The app itself was unaffected — it always played the right
set — but the offline download, which picks its content a different way, was pulling the
old set down alongside the new one. Anyone who downloaded a switched course for offline
use today got roughly twice the listening audio they needed, with the retired recordings
in the mix. All 21 have been marked properly, and downloads now carry one set per course.
If you downloaded a course for offline use earlier today, re-downloading it will clear
the extra.

**A small number of Dutch learners had their dialogue progress repaired.** Fourteen
progress records were left pointing at the wrong place by a timing collision during the
Dutch switchover — progress saved at the exact moment the new conversations were being
swapped in. They have been repaired, and a guard now folds in anything that lands
mid-switchover so it cannot recur.

## Risk on the dialogues

Low for the app, moderate-and-managed for the content.

The dialogue change itself is content, and it reached learners earlier today through the
course database rather than through this app release. It was gated on a hard rule: a
course flipped only if every one of its 231 lines had finished, verified audio on **both**
tracks, with every clip in the right speaker's voice. All 21 courses cleared that gate on
their own measurement, taken from the live database at the moment of the switch rather
than from an earlier report. Every replaced conversation set is archived rather than
deleted, and each switch carries a one-line rollback.

Progress migration across all 21 courses moved 214 records covering 4,247 exposures, with
zero mis-credits and zero orphaned records at the point of commit — with the exception of
the Dutch fourteen above, which arrived after that check and have since been repaired.

## What we are watching

- Dialogue progress on the 21 switched courses — anyone landing back at the start of the
  dialogues when they were partway through would mean the migration missed a case.
- Voices within a single conversation: two distinct speakers, never the same voice on both
  sides of an exchange.
- Offline downloads on the switched courses returning the new 231-line set, and never a
  set still in preparation.
- The remaining courses, Icelandic among them, for the next release.

**Two security holes closed.** Nothing a learner does differently, but worth stating
plainly. The code that grants the highest level of administrative access was being
generated from a source that was not properly random, and so was more guessable than it
should ever have been. It now comes from a proper cryptographic source. Separately, the
page where you redeem a code — a class code, a school code — had no limit on how many
times it could be tried, so someone could have sat and guessed at it indefinitely. It now
has one.

That limit is set with schools in mind. A teacher signing up a whole class does it from
one building, so thirty children redeem perfectly valid codes from what looks to us like
a single connection, within minutes of each other. The limit is set well above three full
classes back to back, so no child is ever turned away holding a code that works.

## Risk on the security change

The throttle is the one piece here that can say no to a real person, so it is worth being
straight about it. A per-connection limit only ever bounds one connection; someone
determined and well-resourced routes around it. What it does is stop the page being a
quiet place to sit and guess — every attempt, including the refusals, is now recorded. It
is a meaningful lock, not a perfect one, and we would rather say that than overstate it.
