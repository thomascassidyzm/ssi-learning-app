# Release — 24 August 2026

## What changes for learners

**Nothing you can see.** This release carries no change to the player, the audio, your progress, or any number on your Library page. If you are mid-course, you will not notice this happened.

That is the honest summary. The detail below is for the record.

## What actually landed

**A dead end when you follow an admin link signed out.** If you clicked a link into an admin page while you were signed out, the app used to drop you into the player instead — the wrong place, with no way to tell why. It now takes you to sign-in, and on to the page you asked for. This only affects staff and school admins; learners never see these links.

**A demo panel that showed stale numbers.** On the demo schools data, the "Last 7 days" panels read from a rollup that the refresh button was not writing. Refresh now writes the rollup those panels read, so a demo shows what it says it shows. This touches demo data only — no real learner's numbers were ever wrong because of it.

**Written notes, no code.** The rest is documentation: an inventory of learner-facing features that sit off the default path, the adoption numbers behind it, and an export of the How This Works copy so it can be edited outside the app.

## Risk

Low. No database migration. No change to the learning engine, audio, scheduling, or progress storage. The two code fixes are confined to the admin sign-in redirect and a demo-data script.

## What we are watching

- Staff and school admins reaching admin pages from a signed-out link — should now land on sign-in, then the page they asked for.
- Demo "Last 7 days" panels agreeing with the data after a refresh.

## Already live, noted here for completeness

Three earlier batches — the join-code security fix, the speech-latency telemetry work, and the Library numbers (Phrases learnt, Phrases spoken, Total Time) — reached production ahead of this release, between 22 and 24 August. Their database migration is applied and verified. They are not part of this release; this note records that they preceded it.
