# Public roadmap — READ VERBATIM BY THE SUPPORT AGENT

**Every line below this header is handed, word for word, to the in-app support drafter when a
learner or admin asks what is coming or when.** Write here only what you are happy for a learner
to be told. Nothing here is invented by an agent: a line is either a plan a named owner has
written down, or a placeholder that says there is no written plan yet. Keep it that way.

Rules for editing:
- One line per item, plain words, no dates unless the owner is committing to the date.
- No parentheses. British spelling.
- A placeholder reads `not written yet — ask <owner>`; the agent then tells the learner honestly
  that it is not decided or written down yet and passes the question on. It never names the owner.
- Delete a line when it ships; the release train's own notes carry what shipped.
- The weekly ship day and what is on the next ship are derived from the release train
  automatically. Do not write them here.
