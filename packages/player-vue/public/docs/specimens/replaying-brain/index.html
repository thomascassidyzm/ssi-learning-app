Where this data comes from, and what is missing

  • Source. The learner app's own play log, one row per audio played, for the class account of 8H. A cycle counts once the class heard the Welsh target, so 5 cycles where only the English prompt played before a pause or skip are not counted. Of the 53 counted: 8 chunk introductions, 6 chunk debuts, 39 build phrases, 0 use phrases.
  • The lines are rebuilt, not read. The app has a co-firing table for exactly this picture, but for every class in every school it is empty: a class plays under a class account whose identity is not the teacher's, and the table's own security rule refuses the write, silently. The pupils' accounts are untouched by class play. So each arc here is derived the way the app itself derives co-firing, from the chunks that make up the phrase that was actually played, taken from the play log cycle by cycle with its real timestamp. No arc is drawn from course structure alone: a phrase never played draws nothing.
  • Why 8H. Chepstow's 33 classes have between them 901 heard cycles, Thu 16 Jul to Wed 16 Sept. 8H and 7H are tied for the most cycles of any class, 53 each across three sittings; 8H is shown because it covers the most distinct phrases. No other real school has any class play yet; every other class with sittings in the database is a demo school.
  • Stepping. The scrubber moves cycle by cycle inside a sitting, and the sitting buttons jump between sittings. Weeks are not offered because 8H's own record spans 5 days (Mon 7 Sept to Fri 11 Sept); it's the wider school, Thu 16 Jul to Wed 16 Sept, that runs to weeks.
  • The school layer is the other 32 Chepstow classes' cycles up to the same moment, drawn faint below the line. 12 of their cycles carry an older cycle id that names the chunk but not the phrase; those light the chunk and draw no arc.
